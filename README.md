# 기관 연속 순매수 백테스트

`institutional_backtest.py` — 최근 3년간 **기관이 3일 연속 순매수한 종목을 다음날 시가에 매수해 5거래일 보유**했을 때의 승률과 수익률을 백테스트합니다. (KOSPI + KOSDAQ 전 종목, 데이터: [pykrx](https://github.com/sharebook-kr/pykrx))

## 실행

```bash
pip install -U pykrx pandas numpy
export KRX_ID=내_KRX_아이디      # data.krx.co.kr 회원 계정
export KRX_PW=내_KRX_비밀번호
python institutional_backtest.py
```

최신 pykrx는 KRX 정보데이터시스템에 로그인해야 데이터를 받을 수 있어서 `KRX_ID`, `KRX_PW` 환경 변수가 필요합니다. 계정은 [data.krx.co.kr](https://data.krx.co.kr)에서 무료로 만들 수 있습니다.

첫 실행 때 거래일별 전 종목 시세와 기관 순매수를 KRX에서 받아 `cache/`에 저장합니다. 약 750거래일 × 4번 요청이라 시간이 좀 걸리고, 두 번째 실행부터는 캐시를 씁니다.

## 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--years` | 3 | 백테스트 기간(년) |
| `--end` | 어제 | 종료일 `YYYYMMDD` |
| `--streak` | 3 | 기관 연속 순매수 일수 |
| `--hold` | 5 | 보유 거래일 수 (진입일 포함) |
| `--min-value` | 0 | 신호일 최소 거래대금(원), 예: `1e9` |
| `--fee` | 0.00015 | 편도 수수료율 |
| `--tax` | 0.002 | 매도 거래세율 |
| `--allow-overlap` | off | 보유 중인 종목에 새 신호가 나도 중복 진입 허용 |
| `--out` | trades.csv | 거래 내역 저장 경로 |

## 규칙

- **신호**: `기관합계` 순매수거래대금 > 0 이 N일 연속 (D-2, D-1, D)
- **진입**: D+1 시가
- **청산**: 진입일 포함 5번째 거래일(D+5) 종가
- **수익률**: `(진입일 종가/시가) × Π(1+일별 등락률)` 방식이라 액면분할 등 가격 불연속의 영향을 받지 않음
- 진입일 시가가 없는(거래정지) 종목은 제외하고, 보유 중 상장폐지·정지되면 마지막 종가로 청산 처리
- 기본값은 같은 종목을 보유하는 동안 들어온 신호는 무시

## 출력

- 전체 성과: 거래수, 승률, 평균/중앙값 수익률, 평균 이익/손실, 손익비 (비용 차감 전후)
- 연도별 성과
- 포트폴리오 근사: 자본을 5등분해 매일 한 몫씩 그날 신호 종목에 동일가중으로 투입했을 때의 누적수익률과 MDD
- `trades.csv`: 개별 거래 내역

## 한계

- 날짜별 KRX 전 종목 데이터를 쓰므로 이후 상장폐지된 종목도 포함되어 생존편향은 작습니다. 다만 시가 체결 가능성과 슬리피지는 반영하지 않습니다.
- 기관 순매수 데이터는 장 마감 뒤에 확정되므로 D일 장 마감 후 신호 → D+1 시가 진입은 실제로 실행할 수 있는 구조입니다.
